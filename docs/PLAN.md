# Rakkan 开发计划

> 每个字都有落款 · Every character, signed.

本文件是开发计划，规范以 [SPEC.zh.md](SPEC.zh.md) 为准。

## 结构

一个仓库、一个 `package.json`，分三层：

```
src/core/      纯 TypeScript 解析器：不 import obsidian，不碰 Node、DOM
src/cm6/       实时预览装饰 + 自动标注，只依赖 @codemirror/*
src/obsidian/  设置、命令、状态栏、阅读视图
scripts/       统计脚本等小工具（用 core，跑在 Node 上）
tests/         vitest 单元测试；tests/fixtures 是样例库（全是假数据）
```

- `@codemirror/*`、`obsidian` 在打包时设为 external
- core 逐字扫描，不用正则 lookbehind（iOS 16.4 以下不支持）
- manifest `isDesktopOnly: false`

## 待办

- **已核对的引文**（SPEC §4.4）：模型写的引文是模型的声明，字仍算模型的；有证据的可以升级，字归 key。证据三种来源：MCP 加一个 quote 工具，由工具自己读原文、确认是子串后写入，出处标记由工具写；引文链接到库里的原文（块引用、剪藏快照），lint 逐字比对；人在插件里手动确认。写法未定。现在解析结果里的 `claims`（范围 + key）就是给它留的位置
- **agent 入口的引用默认 untrusted**（Q1）：`quoteText` 有两种输出。默认给笔记里粘贴、剪藏进来的 Markdown：`& %` 和能组成标记的 `@`（连着另一个 `@`，或紧跟在 `[` 后面）转义，单独的 `@` 不动，邮箱照样是链接；反斜杠不动，没闭合的代码围栏和 `$$` 块在 `[@key]` 行前补上，渲染出来和原文一样（P6 对照 markdown-it）。`{ untrusted: true }` 给纯文本（设备、网页正文、agent 拿到的外部文字）：ASCII 标点全转义，显示的是原来的字符。以后 MCP 的 quote 工具和 CLI 的引用命令默认用 untrusted
- **P6 里"隔离优先"的几类逐类收掉**（投完 Ericsson 再做）：以 P6 为参照，把排除表里解析器和 CommonMark 读法不同、按隔离优先处理的几类逐类收掉。先做两类：围栏读法不同（fences read apart，约占输入的 8%），和裸 URL 盖住反引号（URL over a backtick；GFM 里代码 span 优先于裸 URL，解析器改成同样的优先级）。之后是公式读法不同（math read apart）、在中途闭合的未闭合 `$$`（math left open mid-text）、公式盖住反引号、代码 span 保持跨行、列表变松散。split-code-span 也考虑在插件里显示（状态栏提醒）。P6 的单行生成器含制表符，整段生成器还不含；缩进里的制表符已按原来的列展开，围栏内容行里的制表符未处理
- ~~`a\@b.c` 在 Obsidian 里是否仍是邮箱链接~~（Q1）：手测确认不再是链接，已改成只转义能组成标记的 `@`（连着另一个 `@`，或紧跟在 `[` 后面）

## git 约定

- `main` 保持可构建；每个里程碑一个或几个提交，提交信息用 Conventional Commits（`feat(core): …`）
- 仓库根目录的 Markdown 一律忽略，只放行 README.md、README.zh.md、CHANGELOG.md
- 测试样例、示例、截图里的 AI 署名只用模型家族名（Claude、GPT），不拷任何真实笔记
