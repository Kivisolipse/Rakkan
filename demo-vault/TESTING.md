# 手测清单

在 demo-vault 里逐项测试，通过的勾上，不对的在该项下面记一句现象。每次 `npm run demo` 之后，在「设置 → 第三方插件」里关闭再打开 Rakkan，重新加载插件。

文末「练习区」里有各项要用的样例，可以随意改。`示例：分页` 是现成的完整示例，`Search sample` 是搜索用的样例。本清单里也写着要搜的词，搜索结果里会出现本清单，看 `Search sample` 在不在即可。

- [x] 阅读视图：着色与实时预览一致，看不到任何标记
- [x] 命令「切换写作 / 审阅显示」：写作模式下颜色变淡，审阅模式下完整颜色
- [x] 设置里关闭「实时预览隐藏标记」后标记始终显示；重新打开后恢复
- [x] 彩虹字、渐变字：在设置里把「AI 文字样式」改成彩虹字，颜色随字在版面上的横向位置从橙到蓝变化；深色主题下同样鲜明，不发暗；改回彩色字

- [ ] 悬停预览（按住 Ctrl 悬停一个指向 `示例：分页` 的链接）里同样着色

## 3. 输入

- [ ] 在 `@@…@@` 末尾按 Enter：新行不在岛内
- [ ] 删光一个岛里的字：`@@@@` 一并消失；删掉两个岛之间的 AI 文字：两个岛合并成一个
- [ ] 在 `&&…&&[@claude]` 行内 AI 里打字，同样自动标注原创
- [ ] 在引用 `「…」[@fakebook]` 里打字，同样自动标注原创
- [ ] 在 AI 块的代码块里打字：自动给代码块加上声明（如 ```` ```ts @@ ````）并包进岛；删光岛后声明一起删除
- [ ] 往已声明 `@@` 的代码块里粘贴含 `@@` 的文字（如 diff 的 `@@ -1 +1 @@`）：声明和已有的岛一起加长为 `@@@`
- [ ] 在练习区的公式里（AI 块中，已写 `$$ %@@`）打字：新打的字包进 `@@…@@`
- [ ] 打 `[@` 弹出作者列表，选中后补全 key；中文输入法下打 `【@` 自动换成 `[@` 并弹出列表
- [ ] 设置里关闭「自动标注原创」后不再自动包；重新打开后恢复
